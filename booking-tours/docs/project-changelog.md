## [v2.5] 2026-08-04 — Day 5 (T5): Reflection-based Excel Mapper

### Added
- `@ExcelColumn` annotation — maps DTO fields to column index + label; drives both export header generation and import row parsing
- `ExcelMapper<T>` — generic `@Component`; `exportRow(T, Row, CellStyle)` writes a row via reflection; `importRow(String[], Class<T>)` constructs a DTO from a raw `String[]` via reflection; `COLUMN_COUNT` derived at runtime from annotation count
- `ExcelValueCodec` — encode/decode helper: `String → typed field value` and `typed value → String` for all column types used by the DTOs
- `BookingExcelRow` — export DTO; fields annotated with `@ExcelColumn`
- `TourExcelRow` — import DTO; fields annotated with `@ExcelColumn`
- `ExcelMapperTest` — 7 JUnit 5 unit tests covering round-trip encode/decode, null handling, and column count derivation

### Changed
- `BookingExcelExporter` — delegates all row/cell logic to `ExcelMapper`; reduced from 107 → 57 lines
- `TourExcelImporter` — replaces manual index-based cell reads with `mapper.importRow()`; `COLUMN_COUNT` is now reflection-derived

### No breaking changes
No public service API changes, no new endpoints, no DB schema changes.

## [v2.4] 2026-08-03 — Day 4: File Handling, Multithread & SOAP

### Added

**Apache POI Excel Export**
- `BookingExcelExporter` — generates styled `.xlsx` using `XSSFWorkbook`; header fill `#BDD7EE`, bold font, border; alternating row fill `#F5F5F5`/white; auto-sized columns
- `ExcelExportService` / `ExcelExportServiceImpl` — calls `BookingService.search()` with `Pageable.unpaged()` to pull all matching rows
- `GET /admin/bookings/export` — passes same query filters as the booking list page; responds with `Content-Disposition: attachment` and correct MIME type
- "Export Excel" button on admin bookings list page

**Multithreaded Excel Import**
- `importExecutor` `ThreadPoolTaskExecutor` bean in `AsyncConfig` (core=5, max=10, queue=50, `CallerRunsPolicy`)
- `TourExcelImporter` — reads POI rows into `String[][]` on calling thread, fans each row out to `importExecutor` via `CompletableFuture.supplyAsync()`; aggregates `ImportRowResult`
- `ExcelImportService` / `ExcelImportServiceImpl` — validates rows independently, tracks job state, calls importer, persists valid rows as `INACTIVE` tours
- `TourImportJob` entity with `ImportJobStatus` enum (`PENDING` / `PROCESSING` / `COMPLETED` / `FAILED`)
- Flyway **V9** migration `create_tour_import_jobs_table.sql`
- `GET /admin/tours/import` — shows upload form + recent jobs table
- `GET /admin/tours/import/template` — serves downloadable `.xlsx` template (generated by POI)
- `POST /admin/tours/import` — accepts `MultipartFile`, runs import, redirects with flash summary
- `templates/admin/tours/import.html`

**Spring WS SOAP**
- Manual JAXB classes (no codegen): `CurrencyConversionRequest` / `CurrencyConversionResponse`
- `CurrencyRateProvider` — hard-coded VND base rates: USD 25 500, EUR 27 800, JPY 170, KRW 18.5
- `CurrencyConversionEndpoint` — `@Endpoint` mapped at `/soap/*`; `@PayloadRoot` handles `CurrencyConversionRequest`
- `CurrencyConversionClient` — `WebServiceGatewaySupport` subclass; calls local `/soap` endpoint
- `WebServiceConfig` — registers Spring WS `MessageDispatcherServlet` on `/soap/*`; WSDL served at `/soap/currency.wsdl`
- `TourController.tourDetail()` — calls SOAP client for USD and EUR equivalents; passes `priceUsd`, `priceEur` to model
- Tour detail page displays "≈ X USD / ≈ Y EUR" below VND price

## [v2.3] 2026-08-02 — Day 3: Realtime & Scheduler

### Added
- WebSocket + STOMP endpoint `/ws` with SockJS fallback
- `NotificationController` — REST (`/api/notifications`) + STOMP push via `SimpMessagingTemplate`
- `notification.js` — SockJS/StompJS client; updates badge without page reload
- Notification bell icon with unread badge in navbar; `/profile/notifications` page
- `AutoCompleteBookingJob` — cron `0 30 0 * * *`; marks past-departure CONFIRMED bookings as COMPLETED
- `PendingPaymentCleanupJob` — cron `0 0 1 * * *`; cancels PENDING bookings older than 48 h with no payment
- `scheduled_job_logs` table (Flyway V8)
- `AsyncConfig` — `notificationExecutor` (core=3, max=5) and `importExecutor` (core=5, max=10) beans
- `@Async("notificationExecutor")` on `NotificationService.saveNotification()` and `broadcastTourPromotion()`

## [v2.2] 2026-08-01 — Day 2: Messaging

### Added
- ActiveMQ embedded broker (vm://localhost); `booking.notifications` queue
- `BookingNotificationProducer` / `BookingNotificationConsumer`; consumer persists to `notifications` table

## [v2.1] 2026-07-31 — Day 1: Foundation & Infrastructure

### Added
- MySQL 8 migration: replaced PostgreSQL driver; rewrote V1–V5 Flyway scripts to MySQL syntax (`AUTO_INCREMENT`, inline ENUM, InnoDB charset)
- `MdcLoggingFilter` — injects `requestId` (UUID) and `userEmail` into MDC for every request
- `logback-spring.xml` — three appenders: `app.log` (INFO+, 30-day rolling), `error.log` (ERROR only), `audit.log` (security events)
- Swagger / OpenAPI 3.0 via springdoc 2.6.0; JWT Cookie security scheme; 14 controllers annotated with `@Tag` + `@Operation`; disabled in prod/test profiles
- `CustomStandardOAuth2UserService` — handles Facebook (Graph API `/me?fields=id,name,email`) and Twitter (API v2 `/2/users/me`, synthetic email `twitter_{username}@noemail.local`)
- `CustomAuthorizationRequestResolver` — `prompt=select_account` scoped to Google only
